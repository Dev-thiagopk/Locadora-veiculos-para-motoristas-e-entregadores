## 🚗 Sobre o CarLog

O **CarLog** é um sistema de locação de veículos desenvolvido para
atender **motoristas e entregadores** que precisam de um veículo
para realizar suas atividades profissionais.

---

## 🎯 Objetivo

Criar uma solução digital que facilite o processo de **locação e
gerenciamento de veículos**, proporcionando uma experiência simples
e organizada para os usuários.
